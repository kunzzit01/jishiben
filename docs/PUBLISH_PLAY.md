## 二、⚠️ 最大的坑：新个人账号必须先封闭测试

自 2023 年 11 月起，**新注册的个人开发者账号**发布正式版之前，必须：

```
封闭测试（Closed testing）
  · 至少 12 名测试者
  · 连续 14 天
  · 测试者需接受邀请并安装
```

满 14 天后才能申请「生产访问权限」（Production access），Google 人工审核通过才能公开发布。

> 这意味着：**从注册账号到能公开上架，最快也要 2–3 周**。
> 如果你有公司账号（组织账号），不受此限制。

**建议立刻做的事**：账号一拿到就创建应用 → 上传 AAB → 开封闭测试 → 找人装 →
这 14 天可以用来完善列表素材，不浪费。

## 三、隐私政策页（已就绪）

文件：`deploy/public/privacy.html`，由 web 容器的 nginx 直接提供：

```
http://<你的地址>:<HTTP_PORT>/privacy
http://<你的地址>:<HTTP_PORT>/privacy.html
```

部署后验证：

```bash
cd /opt/jishiben && git pull
docker compose -f deploy/docker-compose.yml up -d --build web
curl -sI http://localhost:8088/privacy | head -3     # 期望 200 + text/html
```

> ⚠️ Play 要求隐私政策 URL **可公开访问且不需要登录**。
> 用裸 IP（`http://187.127.125.136:8088/privacy`）技术上能用，

## 四、构建 AAB

```bash
cd <仓库根>
npx eas-cli build -p android --profile production
```

- `production` profile：`buildType: app-bundle`，产出 **.aab**
- `autoIncrement: true`：versionCode 由 EAS 自动递增
- 首次会要求确认签名密钥（沿用已有 keystore，保证可升级）

## 五、Play Console 操作顺序

1. **创建应用**：Play Console → 所有应用 → 创建应用
   - 应用名：记账本（或你定的中文名）
   - 默认语言：中文（简体）
   - 应用或游戏：应用　·　免费
2. **设置 → 应用完整性**：确认启用 Play 应用签名（上传 AAB 时 Google 会接管签名）
3. **测试 → 封闭测试**：创建轨道 → 上传 AAB → 添加 12 名测试者邮箱
4. **商店设置**：
   - 商店列表（图标 512 / 特色图片 / 截图 / 描述）
   - 内容分级问卷
   - 目标受众
   - **数据安全表单**（见下）
5. 14 天后 → **生产 → 申请访问权限** → 提交审核

## 六、数据安全表单怎么填（照这个填）

| 问题 | 答案 |
|---|---|
| 应用是否收集或分享用户数据？ | **是**（收集） |
| 收集哪些类型？ | 个人信息 → 邮箱；财务信息 → 用户录入的账目；照片/视频 → 可选的小票图片；音频 → 可选的语音记账；应用活动 → 账目 |
| 数据是否加密传输？ | 生产环境启用 HTTPS 时为「是」；裸 IP + HTTP 时必须填「否」，并说明 |
| 用户能否请求删除数据？ | 是（应用内删除 + 邮件申请） |
| 是否与第三方共享？ | 仅在启用 AI 识别时把当次内容发给模型服务商 |

> 这条很关键：**如果你还用 `http://裸IP:8088`，数据安全表单只能填"未加密传输"**，
> 审核可能因此打回。这是"必须上 HTTPS"的另一个硬理由。

---

## 七、常见拒审原因（提前规避）

| 原因 | 规避 |
|---|---|
| 隐私政策 URL 打不开 / 需要登录 | 用 `/privacy` 公网直达，先自己用手机流量试一次 |
| 数据安全表单与实际行为不符 | 按上面第六节如实填 |
| 传输未加密 | 上 HTTPS（Cloudflare / 现有反代 / certbot 均可） |
| 缺少测试说明（封闭测试） | 给测试者写清「装完注册账号即可」 |
| 应用崩溃或无响应 | 上架前在真机跑一遍核心流程 |
